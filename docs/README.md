# Bentropy

> Fighting entropy, one project at a time.

**Bentropy** is a personal portfolio and command center for Ben, an entrepreneur who builds prototype web applications. The name combines "Ben" + "Entropy" — representing the constant battle to bring order to the chaos of creative ideas.

## Philosophy

The universe tends toward disorder. Ideas scatter across browser tabs. Projects multiply and fragment. The chaos is constant.

Bentropy is the deliberate fight against that chaos. Each project shipped is a small victory. Each idea made real is entropy temporarily reversed.

This philosophy drives every design decision:
- Particle animations that crystallize from chaos into order
- A cosmic nebula background representing the void
- An "entropy meter" tracking current chaos levels
- Project narratives structured as Problem (chaos) → Solution (bentropy applied) → Outcome (order achieved)

## Features

### Public Site
- **Landing Page**: Particle animation hero with crystallizing "Bentropy" text
- **Projects Gallery**: Filterable showcase of all projects
- **Project Detail**: Deep-dive pages with the entropy narrative
- **About**: The Bentropy philosophy and skills

### Admin Dashboard (Command Center)
- **Dashboard Home**: Stats, entropy meter, quick actions
- **Projects Manager**: CRUD for public site projects
- **Credentials Vault**: Encrypted API keys and secrets
- **Local Services**: Track dev servers and ports
- **Repository Hub**: Links to GitHub repos
- **Login Tracker**: Encrypted credential storage
- **Notes**: Markdown scratchpad

## Quick Start

```bash
# Install dependencies
npm install

# Run development server on port 3344
npm run dev -- -p 3344

# Build for production
npm run build
```
