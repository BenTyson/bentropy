# Bentropy

> Fighting entropy, one project at a time.

Personal portfolio and command center for an entrepreneur who builds prototype web applications.

## Quick Start

```bash
npm install
npm run dev -- -p 3344
```

Open http://localhost:3344

## Tech Stack

Next.js 15 • Tailwind v4 • Framer Motion • tsParticles • shadcn/ui • Supabase

## Features

**Public Site**: Landing page with particle animation, project showcase, about page

**Admin Dashboard**: Command center with entropy meter, projects manager, credentials vault, local services tracker, notes
